# 8.3 Rastreabilidade

A rastreabilidade relaciona o problema às declarações dos requisitos pela cadeia **objetivo específico (OE) → característica de produto (CP) → requisitos funcionais e não funcionais**. Os objetivos, as características e seus valores de negócio estão definidos na [seção 2](2.solucao-proposta.md#23-caracteristicas-de-produto-cp).

Esta página não mantém vínculos próprios: as relações são montadas a partir do campo de origem de cada registro do [catálogo de requisitos](8.1requisitos-software.md). Para alterar um vínculo, altera-se o registro do requisito.
